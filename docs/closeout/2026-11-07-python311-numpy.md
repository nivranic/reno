# Python 3.11 依赖兼容修正

项目 `pyproject.toml` 声明 Python >=3.11，checkpoint-runtime 使用 Python 3.11；原 requirements.txt 无条件固定 NumPy 2.5.3。

本轮从 PyPI 的精确发行版元数据取得以下事实：

| 发行版 | 官方 Requires-Python | 来源 |
| --- | --- | --- |
| NumPy 2.5.3 | >=3.12 | [PyPI JSON](https://pypi.org/pypi/numpy/2.5.3/json) |
| NumPy 2.4.6 | >=3.11 | [PyPI JSON](https://pypi.org/pypi/numpy/2.4.6/json) |

2.4.6 是查询时 2.4 系列最新正式版，存在未撤回的 CPython 3.11 manylinux x86_64 wheel。元数据只用于兼容性判断，没有下载或执行 NumPy。

原无条件固定版本与项目声明的 Python 3.11 范围不相容。修正使用标准环境标记：Python <3.12 选择 NumPy 2.4.6，Python >=3.12 选择 NumPy 2.5.3。项目最低版本仍为 >=3.11，其他依赖的版本与顺序保持。

## 已验证与待验证

用现有 packaging 控制工具解析完整 requirements，并核对 Python 3.11.0、3.11.14、3.12.0、3.12.10、3.13.0、3.14.0 六个版本的标记选择；每个版本恰选一项，选中版本满足对应发行版 Requires-Python。其他依赖声明逐项保持，`git diff --check` 通过。控制检查不导入产品或 NumPy，不安装、下载依赖，也不改变正常服务的环境。
