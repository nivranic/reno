## 1. 选择：原行为在前，共同认可与实际消费在同一 native 调用中

不采用有限轮 Python getter 重读，也不将所有 root 锁同时持有。选择三个明确阶段：准备独立来源及 actual 操作数；执行原工具 body，包括原 getter/audit/逐 root 单锁/finally；仅在原调用成功后，在持续持有 GIL 的 C 成功段共同核对 current metadata、独立 source/fact 和 actual return，再作本次认可或在同一 C body 尝试原下一调用。

原工具成功只作 preliminary，不是认可凭证。最终段不调用 Python getter/hash/eq/descriptor/audit，不分配容器/记录，不 DECREF，不放 GIL、不等待、不处理 pending callbacks。所需数组/强根/参数缓冲/结果选择和可再入清理在最终段前准备，并在全部准备后重核。最终失败只记录 C 错误枚举，离开该成功段后才构造新增认证错误；不清洗字段后重试成功。

本设计区分两个结果：TMD 在该有限共同点认可实际 metadata/原返回；AD 在同一 C body 的调用消费点将 source/phase/callee/实际参数 fresh 检查与实际 call attempt 相连。TMD 不授予以后任意 subject 调用的永久权限；AD 的 D0 也不自动证明 frame/code/参数建立的 D1、closure 消费的 D2 或整个 body 不变。

原 function_row/module_row/class_row 的实际返回可提供原读数；原 check_view 只返回 selected，没有返回各 root 的局部历史快照。**不虚构这些 locals 已运输，不新增锁内 recorder、runtime journal 或全 snapshot 返回 ABI。**最终重跑原谓词、联系原实际返回和独立 source，而不是声称所有历史读数从未改变。

## 3. 最终段的有限 C 操作白名单

本批只论证 CPython v3.12.10 持 GIL 路线；不靠关闭 GC/trace/monitoring/PEP523。tagged 源与本机 SDK export 表是静态证据，不是 native link/build/runtime 或 DLL 源码身份自证。free-thread 版本、其他 CPython 版本和平台另列 COMPAT，不缩 pyproject >=3.11。

访问器头文件下载两次均已确认进程终止；保留已取得的两个tagged头，剩余cell/dict/module三份采用本机3.12.10 SDK的只读完整副本。它们标为SDK来源，不宣称已核对upstream tag身份，不继续重试网络、不更改网络配置。module内部头的非NULL前提、cell NULL状态和dict raw size均在这些实际SDK文本中核对；本方不include需要Py_BUILD_CORE的module内部头，具体layout声明/构建仍待审。

wrapper/accessor 的额外 source guard 若需要读 exact property/staticmethod/classmethod 当前链接，使用固定3.12.10布局的本地声明与 byte-offset memcpy 读取，先严格验原 exact type；避免不相容结构指针别名访问，也不调用 descriptor。property 的内部头要求 Py_BUILD_CORE，本方不直接 include；其 full layout/CM-SM声明、NULL→Py_None成员语义、offset/sizeof、许可及各版本仍须在具体源码与构建审查中验证。本批没有生成 C 源码或声明这些 ABI 已通过。

## 4. 逐协议的共同谓词与 root 单锁路线

函数协议检查原 code/defaults/kwdict身份与全部entries、原 closure tuple和各cell身份/空态/content、G/B实际关联与全部exact-str键；kwdict长度及每条原entry的值identity同时成立。defaults tuple 内普通对象不被无根据地递归冻结。empty cell 是 NULL，不是内容 Py_None；原 cells记录的 populated bool、missing原对象和empty分支均须区分。

dict name 查询返回 effective value：找到则为 actual value，否则为本次原 private missing。故“缺键”和“key存在且值就是该原 missing”在原 dict_get 语义下可能相同；不能统一改成必须found。kwdict/class entries 按原长度、每entry形状及查询谓词检查，不暗增原本没有的遍历顺序或额外一一覆盖条件。独立原来源的完整性另由 source guard 保证，不能靠改纯工具语义替代。

module/class/binding 也按原谓词：MRO actual identity、exact-type各base、每base entries长度和目标值、所有键类型、每个dispatch函数row及result选择；binding4 的 present=True要求 effective actual 非missing且identity==original，False要求 effective actual==missing。不要求 G/B 或 root data 的全部无关 value 永远不变。

root5 的实际 lock/slot/data/name/allow_unpublished 必须与原 actual view 和独立 source 对应；slot是exact list长6，顺序为 phase/present/original/store_attempted/effect/failure_code。保持原逐root行为：acquire在try外；try内读slot、扫键、dict_get并检查；finally单独release；正常退出后才递增root_index。不新增多锁嵌套、不跨原业务/helper调用持metadata锁，也不为了最终段重跑acquire/release。

| 最终 root 分支 | 必须共同成立的原条件 |
| --- | --- |
| 通用 | phase exact int；present/store_attempted exact bool；failure_code为None；data所有key exact str |
| phase0 | allow_unpublished=True；original=None；store_attempted=False；effect=None；present=True时effective actual=None，否则effective actual=原missing |
| phase2 | present/store_attempted=True；effect及effective actual均identity==original；original为exact tuple或exact function |
| 其余 | 拒绝，phase1不因partial而新接受 |

全部原release和其他可再入准备结束后，最终段重跑这些原root谓词及独立source/fact，形成一个共同认可点；**GIL不替代原锁的获取/等待/异常语义**。限定本段无Python回调、无GIL释放及正常协议写方需持GIL，才可连续读取其当前状态；不纳入违反解释器规则的无GIL内存写或任意原生内存改写。

最终不要求每个未选root的旧phase/旧actual不变：它可从原读时合法phase0转为最终合法phase2，只要最终原谓词及该边source/fact仍成立。所选root须把原实际return与最终original关联：若原返回F1而最终为F2，拒绝；不能认可F2却返回F1，也不能重采样expected。phase0返回None是合法结果。具体原边已有same-phase actual运输要求时仍按其原要求另行接线，这条最终谓词路线不代替该运输。

## 5. 原错误、最终成功点与实际下一调用

原工具调用抛错时立即保留其最终逃逸异常，不进入最终成功门，不重新调用工具、不撤销此前audit/callback/effect。root acquire失败不执行release；try内原失败仍走原finally；若原release自身失败，原Python的覆盖/context关系必须先自然完成。C只在实际call返回NULL后取得那个最终逃逸对象，不能提前保存初始异常再强行覆盖原finally结果。PyErr_GetRaisedException转移该实际对象的所有权，PyErr_SetRaisedException偷取还原；它们不是原finally之前的万能快照恢复。
