## 准备

- [ ] 服务已监听 LAN：`reno serve --host 0.0.0.0`（或反代）
- [ ] 已在 `config.local.json` 设置 `auth_token`（开启 API 令牌门）
- [ ] 手机浏览器打开 `http://<电脑IP>:8765/` → 弹出"需要访问令牌" → 输入令牌 → 刷新后数据可见

## 布局与安全区

- [ ] 底部导航不被 iPhone Home 横条遮挡（`env(safe-area-inset-bottom)`）
- [ ] 顶栏不被刘海/挖孔遮挡
- [ ] 320px 宽度（SE 类）无横向滚动；390/430 正常
- [ ] 系统字体放大到最大档：底部导航增高后列表最后一项仍可完整看到
- [ ] 浅色/深色主题切换，各页无漏适配白块

## 交互与键盘

- [ ] 收件箱 → 点"导入视频" → 全屏面板；粘贴按钮可用（或回退长按粘贴）
- [ ] 导入面板输入框聚焦：软键盘弹出后"导入并处理"按钮仍可达
- [ ] 搜索页进入时不自动弹键盘；中文输入法合成期间不提前触发搜索
- [ ] 争议复核：选择决定 → 填长备注 → 键盘弹出 → 提交按钮可达 → 提交成功
- [ ] 问答页：提问 → 引用卡片跳转视频时间点 → 返回问答页输入仍在

## 媒体与证据

- [ ] 工作台默认进入"知识"标签；带 `?t=` 深链进入自动切"证据"并定位
- [ ] 竖屏视频按比例显示，不撑爆一屏；横屏视频不裁切字幕
- [ ] 点证据行 → 选中高亮在视口内、证据帧加载、视频 seek 成功
- [ ] 快速连点不同证据：不错帧（加载中提示正确跟随最后一次点击）
- [ ] 播放中滚动证据流：自动跟随暂停，"回到当前播放位置"出现且有效
- [ ] 锁屏/切后台 30 秒后返回：任务状态校准，不伪造进度

## 生命周期与网络

- [ ] 提交导入后立刻断网 → 恢复 → 状态真实（无重复导入）
- [ ] 飞行模式切换：错误提示明确（非"没有找到"），恢复后自动重试可读
- [ ] 连续切换 视频/搜索/报告 ≥20 次：无明显变慢（监听器无累积）

## 性能抽查（可选，记录数值）

- [ ] 点底部导航切换 ≈ 即时（<200ms 观感，INP）
