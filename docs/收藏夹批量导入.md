# 收藏夹批量导入指南(B 站收藏夹 / 抖音收藏)

三条路径按平台选择,全部在"用户本人数据 + 不绕过任何技术措施"边界内。

## A. B 站收藏夹:整夹自动导入(推荐)

```bash
# 打开你的收藏夹,复制地址栏完整链接,然后:
.venv/Scripts/python -m reno import-favlist "https://space.bilibili.com/<你的ID>/favlist?fid=<夹ID>"
```

- **公开收藏夹**:匿名直接枚举导入;
- **私密收藏夹**:需要你本人的 cookie——浏览器装 "Get cookies.txt" 类插件,在 bilibili.com 导出 Netscape 格式文件,`config.local.json` 加 `"ytdlp_cookies": "cookies.txt"`;
- 已入库视频按 SHA-256 自动跳过(重复导入零成本),可反复执行;
- `--limit 50` 控制单次数量(建议单日 ≤50,配额考虑)。

## B. 抖音收藏:书签脚本(采集助手页 http://127.0.0.1:8765/collect)

抖音没有公开的收藏列表 API,也不存在官方导出。采用**书签脚本(bookmarklet)**方案:

1. 浏览器登录抖音,打开「我的收藏」页;
2. 把采集助手页里的"➦ 收藏页 → reno"按钮拖到书签栏;
3. 向下滚动收藏页,加载出想导入的视频(书签只提交**当前已加载**的,可多次点);
4. 点书签 → 弹出统计 → reno 首页看队列。

原理:书签在你本人浏览器、本人会话内读取当前页面已显示的视频链接,POST 给本机 reno(已配 CORS 白名单 douyin.com/space.bilibili.com)。无自动化、无风控对抗、无凭据存储。

## C. 抖音视频下载前提(一次性)

yt-dlp 对抖音的下载要求 fresh cookie(**不要求登录**,退出状态导出也可以):

```jsonc
// config.local.json
{ "ytdlp_cookies": "cookies.txt" }   // 从 douyin.com 用插件导出
```

配置后单链接导入照常:`reno import "https://v.douyin.com/xxxx/"`(分享短链直接可用)。

## 批量节奏(重要)

- 单视频全流程约 1–2 万 token;**单日建议 ≤50 个视频**;
- 大批量触碰配额时自动降级路径:`config.local.json` 切 `atomize_model: glm-4.5-flash`(独立配额池)+ `vlm_enabled: false`,次日切回并用 producer 版本机制补跑;
- 混合链接批量:`reno import-batch links.txt`(一行一个,# 注释)或首页"批量导入"文本框。
