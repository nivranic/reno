# 手机采集(iOS 快捷指令,零 App 开发)

## 前提
- 电脑运行 `reno serve`(默认 127.0.0.1:8765;手机访问需监听 0.0.0.0:`reno serve --host 0.0.0.0`)
- 手机与电脑同局域网,或两侧装 Tailscale(推荐,出门也可用)

## 快捷指令配置(iOS「快捷指令」App → 新建)
1. 动作「获取剪贴板」
2. 动作「获取 URL 内容」:
   - URL:`http://<电脑IP或Tailscale域名>:8765/api/import`
   - 方法:POST
   - 请求体(JSON):`{"url":"[剪贴板](快捷指令变量:剪贴板)"}`
   - 请求头:Content-Type: application/json
3. (可选)动作「显示结果」

## 使用
B 站 App 分享 → 复制链接 → 跑快捷指令 → 电脑端自动下载并后台处理(约 2-5 分钟)→ 复核界面刷新可见。

## 安全注意
serve 默认只监听本机;开放局域网/Tailscale 时请勿暴露公网,接口无鉴权(个人内网场景)。需要公网访问时自行加反代+Basic Auth。
